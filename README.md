# Free Flags CDN

Free country flag icon assets served via GitHub Pages at [cdn.freeflags.org](https://cdn.freeflags.org).

## Usage

```html
<img src="https://cdn.freeflags.org/flat-circle/thailand-flag-flat-circle-128.png"
     alt="Thailand flag" width="128" height="128" />
```

Or use CSS classes:

```html
<link rel="stylesheet" href="https://cdn.freeflags.org/css/freeflags.min.css">
<i class="ff ff-th"></i>
```

## URL Pattern

```
https://cdn.freeflags.org/{style}/{country}-flag-{style}-{size}.png
```

- **style** — `flat-circle`, `heart`, `shield`, `drop`, `badge`, etc.
- **country** — Country slug, e.g. `thailand`, `united-states`, `south-korea`
- **size** — `64`, `128`, or `512`

## Available

- 13 icon styles
- 12 countries (Phase 1)
- PNG (64, 128, 512px) + SVG (flat styles)
